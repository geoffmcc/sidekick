Capability Packs (0)

      
A capability pack is an installable area of competence: modules, workflows, knowledge and configuration. Installing or enabling a pack activates executable module code inside Sidekick — there is no process sandbox, only integrity and lifecycle controls. Maturity is evidence-bound: foundation, operational, integrated, then certified.
