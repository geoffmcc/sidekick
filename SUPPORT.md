# Support

Thanks for using Sidekick. Please choose the right place for your question or report so it can be handled efficiently.

## Questions and setup help

Use [GitHub Discussions](https://github.com/geoffmcc/sidekick/discussions), especially the Getting Started discussion, for installation questions, configuration help, and general usage questions.

Before posting, check the README and existing discussions to see whether your question has already been answered.

## Bug reports

Use the [Bug Report issue template](https://github.com/geoffmcc/sidekick/issues/new/choose) for reproducible problems.

Include the Sidekick version or commit, operating system, installation method, steps to reproduce, expected behavior, actual behavior, and relevant logs. Remove credentials, tokens, private keys, and other sensitive information before posting.

## Feature requests

Use the [Feature Request issue template](https://github.com/geoffmcc/sidekick/issues/new/choose) for specific, actionable improvements.

Use GitHub Discussions for broader ideas, use cases, and feedback that are not yet specific enough to become an issue.

## Documentation

For unclear, missing, or incorrect documentation, open an issue and explain which page or section needs improvement.

## Security issues

Do not report security vulnerabilities in a public issue or discussion. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).

## Other support

Please include enough context for someone else to reproduce or understand the problem. Be respectful of other contributors and avoid sharing private system information or secrets.
